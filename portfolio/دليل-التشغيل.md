# دليل تشغيل المشروع — خطوة بخطوة

هذا المجلد يحتوي أكواد الموقع كاملة.
الموقع: سيرة ذاتية مصغّرة + أعمال + خدمات + تواصل + لوحة تحكم للمدير.

------------------------------------------------------------
## الخطوة 1: أين تضع الملفات في XAMPP؟
------------------------------------------------------------
1. اذهب إلى مجلد XAMPP على جهازك:
   C:\xampp\htdocs
2. انسخ هذا المجلد كاملاً (اسمه portfolio) وضعه بداخل htdocs
   بحيث يصبح المسار:
   C:\xampp\htdocs\portfolio
   (يوجد بالفعل على هذا الجهاز — هذه الخطوة مهمة عند النقل لجهاز آخر)
3. تأكد أن بداخله يوجد app.php و index.php و admin و includes و assets.

------------------------------------------------------------
## الخطوة 2: تشغيل Apache و MySQL
------------------------------------------------------------
1. افتح برنامج XAMPP Control Panel
2. اضغط زر Start بجانب:
   - Apache
   - MySQL
(لو المنافذ مشغولة والخدمة لا تعمل، أغلق البرنامج المانع ثم أعد Start)

------------------------------------------------------------
## الخطوة 3: إنشاء قاعدة البيانات يدوياً
------------------------------------------------------------
1. افتح في المتصفح: http://localhost/phpmyadmin
2. من القائمة الجانبية اضغط New (جديد)
3. اسم القاعدة: portfolio_db
4. الترتيب (Collation): utf8mb4_unicode_ci
5. اضغط Create (إنشاء)

------------------------------------------------------------
## الخطوة 4: إنشاء الجداول والبيانات
------------------------------------------------------------
الطريقة الأسهل (استيراد ملف جاهز — ينشئ كل الجداول والبيانات):
1. اضغط على قاعدة portfolio_db في phpMyAdmin
2. افتح تبويب Import (استيراد)
3. اختر الملف: portfolio\install.sql
4. اضغط Go (تنفيذ)

الطريقة اليدوية الكاملة (بدلاً من الاستيراد):
افتح تبويب SQL داخل القاعدة وألصق هذه الأوامر بالترتيب:

CREATE TABLE users (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT,
  username VARCHAR(50) NOT NULL DEFAULT '',
  full_name VARCHAR(100) NOT NULL,
  email VARCHAR(150) NOT NULL,
  phone VARCHAR(30) DEFAULT NULL,
  password VARCHAR(255) NOT NULL,
  role ENUM('admin','user') NOT NULL DEFAULT 'user',
  last_login DATETIME DEFAULT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uq_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE categories (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL,
  slug VARCHAR(100) NOT NULL,
  icon VARCHAR(60) NOT NULL DEFAULT 'fa-folder',
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uq_slug (slug)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE projects (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT,
  title VARCHAR(150) NOT NULL,
  category_id INT UNSIGNED NOT NULL,
  description TEXT,
  image VARCHAR(255) DEFAULT NULL,
  link VARCHAR(255) DEFAULT NULL,
  featured TINYINT(1) NOT NULL DEFAULT 0,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_category (category_id),
  CONSTRAINT fk_projects_category FOREIGN KEY (category_id)
    REFERENCES categories (id) ON DELETE RESTRICT ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE services (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT,
  title VARCHAR(150) NOT NULL,
  category_id INT UNSIGNED DEFAULT NULL,
  description TEXT,
  icon VARCHAR(60) NOT NULL DEFAULT 'fa-server',
  price DECIMAL(10,2) DEFAULT NULL,
  status ENUM('available','soon') NOT NULL DEFAULT 'available',
  featured TINYINT(1) NOT NULL DEFAULT 0,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE settings (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT,
  setting_key VARCHAR(60) NOT NULL,
  setting_value TEXT,
  PRIMARY KEY (id),
  UNIQUE KEY uq_key (setting_key)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE messages (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) NOT NULL,
  subject VARCHAR(200) NOT NULL,
  message TEXT NOT NULL,
  is_read TINYINT(1) NOT NULL DEFAULT 0,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

------------------------------------------------------------
## الخطوة 6: التأكد من بيانات الاتصال
------------------------------------------------------------
افتح الملف portfolio\includes\config.php وتأكد أن:
  DB_HOST  = localhost
  DB_NAME  = portfolio_db
  DB_USER  = root
  DB_PASS  = (فارغ)
(هذه هي القيم الافتراضية في XAMPP ولا تحتاج تعديل)

------------------------------------------------------------
## الخطوة 7: تشغيل الموقع
------------------------------------------------------------
افتح في المتصفح (اكتب الرابط، لا تلمس ملف app.php من Explorer):

  http://localhost/portfolio/app.php

المسارات المتاحة من الملف الواحد:
  app.php                       الرئيسية
  app.php?p=login               تسجيل الدخول / حساب جديد
  app.php?p=logout              خروج
  app.php?p=admin               لوحة التحكم (للمدير)
  app.php?p=admin/projects      إدارة المشاريع
  app.php?p=admin/services      إدارة الخدمات
  app.php?p=admin/categories    إدارة التصنيفات
  app.php?p=admin/messages      الرسائل الواردة
  app.php?p=admin/users         إدارة المستخدمين
  app.php?p=admin/settings      إعدادات الموقع
  app.php?p=admin/digitalplat   حالة النطاق عبر DigitalPlat API
  app.php?p=admin/change_password  تغيير كلمة المرور

يمكنك أيضاً فتح الصفحات مباشرة مثل:
  http://localhost/portfolio/index.php
