# منصة المعرض الشخصي والخدمات الرقمية

موقع وتطبيق ويب متكامل يمثل الهوية الرقمية لمهندس شبكات وأمن معلومات — يجمع بين **معرض الأعمال (Portfolio)** و**عرض الخدمات الرقمية** مع **لوحة تحكم مدير كاملة**.

---

## المميزات

### الواجهة العامة (الزوار)
- قسم Hero تفاعلي مع تأثير كتابة ومؤشرات إحصائية متحركة
- قسم "من أنا" مع مهارات متحركة
- معرض المشاريع مع **فلترة حسب التصنيف** و**بحث فوري**
- نافذة تفاصيل لكل مشروع
- المسؤول يضيف وصفاً لكل مشروع، والزوار **لا يستطيعون قراءة وصف المشاريع إلا بعد تسجيل الدخول** (تظهر رسالة "سجّل الدخول لقراءة وصف المشروع" محل الوصف)
- بطاقات خدمات مع الأسعار وحالة التوفر وطلب الخدمة
- نموذج تواصل يحفظ الرسائل في قاعدة البيانات
- تصميم داكن عصري متجاوب بالكامل (RTL) بخط Tajawal

### نظام الحسابات والأدوار (رابط واحد)
- **رابط واحد موحّد** `index.php` هو نقطة الدخول لكل شيء
- الزائر غير المسجّل: يشاهد الموقع كاملاً باستثناء أوصاف المشاريع (مقفلة)
- تسجيل الدخول / إنشاء حساب جديد: `login.php` (صفحة واحدة تجمع الدخول والتسجيل)
- **مدير** (`admin`): بعد الدخول ينتقل تلقائياً إلى لوحة التحكم الكاملة
- **مستخدم زائر** (حساب جديد أو قائم): بعد الدخول يظهر له الموقع مع أوصاف المشاريع كاملة

### لوحة تحكم المدير
- تسجيل دخول محمي بـ **CSRF + جلسات مشفرة**
- لوحة معلومات (إحصائيات + أحدث الرسائل + أحدث الحسابات + توزيع المشاريع)
- إدارة مشاريع كاملة (إضافة / تعديل / حذف / بحث / فلترة / تمييز) — إضافة الوصف مع كل مشروع
- إدارة خدمات كاملة مع السعر والتوفر والأيقونات
- إدارة تصنيفات
- صندوق الرسائل الواردة (قراءة / حذف / بحث)
- **صفحة المستخدمين**: عرض بيانات الزوار المسجّلين (الاسم، البريد، الهاتف، آخر دخول، تاريخ التسجيل) مع إمكانية حذفهم
- إعدادات الموقع (النصوص، معلومات التواصل، الروابط الاجتماعية)
- تغيير كلمة المرور

### الأمان
- **SQL Injection**: استعلامات محضّرة (PDO Prepared Statements) في كل مكان
- **XSS**: تعقيم كل المخرجات عبر `e()`
- **رفع الصور**: فحص MIME حقيقي عبر `finfo`/`getimagesize`، حد أقصى 2MB، أسماء عشوائية، ومجلد `uploads` محمي من تنفيذ PHP
- **CSRF Tokens** في جميع النماذج
- كلمات مرور مشفرة بـ `password_hash()`

## التثبيت على XAMPP

1. ثبّت **XAMPP** وافتح لوحة التحكم وشغّل **Apache** و **MySQL**.
2. انسخ مجلد المشروع إلى: `C:\xampp\htdocs\portfolio`
3. افتح المتصفح على:
   ```
   http://localhost/portfolio/install.php
   ```
4. اضغط **تثبيت الآن** — سينشئ المثبّت قاعدة البيانات `portfolio_db`، الجداول، البيانات التجريبية، وحساب المدير.
5. بعد نجاح التثبيت:
   - الموقع والبوابة الموحدة: http://localhost/portfolio/index.php
   - تسجيل الدخول / إنشاء حساب: http://localhost/portfolio/login.php
   - لوحة التحكم (للمدير فقط): تسجيل الدخول من نفس الصفحة ثم تحويل تلقائي

> **ملاحظة:** يتم إنشاء ملف `includes/installed.lock` — احذف الملفين `install.php` و `install.sql` بعد التثبيت في بيئة الإنتاج.

### بيانات الدخول الافتراضية
| الحقل | القيمة |
|---|---|
| اسم المستخدم (المدير) | `admin` (أو البريد `admin@localhost`) |
| كلمة المرور | `admin123` |
| المستخدمون الزوار | ينشئون حساباتهم بأنفسهم من صفحة "حساب جديد" |

**غيّر كلمة المرور فوراً**: لوحة التحكم ← تغيير كلمة المرور

## إعدادات الاتصال بقاعدة البيانات

عدّل القيم في ملف `includes/config.php`:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'portfolio_db');
define('DB_USER', 'root');
define('DB_PASS', '');
```

## هيكل المشروع

```
portfolio/
├── index.php                  الواجهة العامة + بوابة موحّدة (حسب الدور)
├── login.php                  صفحة تسجيل الدخول / إنشاء حساب جديد (موحّدة)
├── logout.php                 تسجيل الخروج
├── contact.php                استقبال رسائل النموذج (JSON API)
├── install.php                المثبّت التلقائي
├── install.sql                مخطط قاعدة البيانات + البيانات التجريبية
├── includes/
│   ├── config.php             إعدادات الاتصال
│   ├── functions.php          الدوال المساعدة (DB, أمان, جلسات, أدوار, رفع ملفات)
│   ├── header.php / footer.php
├── assets/
│   ├── css/style.css          تصميم الواجهة العامة
│   ├── css/login.css          تصميم صفحة الدخول/التسجيل
│   ├── js/main.js
│   └── img/projects/          صور تجريبية SVG
├── uploads/                   الصور المرفوعة من لوحة التحكم
└── admin/
    ├── index.php              لوحة المعلومات
    ├── projects*.php          إدارة المشاريع (CRUD)
    ├── services*.php          إدارة الخدمات (CRUD)
    ├── categories.php         إدارة التصنيفات
    ├── messages.php           صندوق الرسائل
    ├── users.php              بيانات المستخدمين الزائرين (عرض/حذف)
    ├── settings.php           إعدادات الموقع
    ├── change_password.php
    ├── api/unread.php         عدّاد الرسائل غير المقروءة
    └── assets/                تصميم لوحة التحكم
```

## جداول قاعدة البيانات
| الجدول | الوصف |
|---|---|
| `users` | الحسابات: المدير (role=admin) والزوار المسجّلون (role=user) + آخر دخول وهاتف |
| `categories` | تصنيفات المشاريع |
| `projects` | المشاريع مع صورها وروابطها وأوصافها |
| `services` | الخدمات مع السعر والتوفر |
| `settings` | إعدادات عامة (نصوص، تواصل، سوشيال) |
| `messages` | رسائل نموذج التواصل |

صورة المشروع يُجلب اسمها عبر **JOIN** مع جدول التصنيفات في صفحات الإدارة والواجهة العامة.
